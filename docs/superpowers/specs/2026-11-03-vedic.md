# 吠陀占星（Jyotish）设计说明

日期：2026-11-03。在八字之外加一套吠陀占星，和八字共用命主、测算记录、提示词 → 粘贴解读 → 导出的流程。

## 命主资料

出生信息加「出生地」（`birth.place`：地名、经纬度、IANA 时区），只有吠陀用。先搜内置的常用城市（`src/vedic/cities.ts`，离线可用），再联网搜 Open-Meteo 地名服务（免费、无密钥、支持中文），都不行可手填经纬度和时区。中国境内一律用 Asia/Shanghai（新疆、西藏出生时间也按北京时间记）。出生钟表时间按时区库换成 UTC，含中国 1986–1991 年夏令时。

命主页的命盘区上方切换「八字 / 吠陀占星」，新建测算跟着当前看的盘走；首页「新建测算」里也可以选。

## 排盘

`src/vedic/astro.ts` 用 astronomy-engine 算行星位置，`src/vedic/chart.ts` 组装星盘：
- 恒星黄道，Lahiri 岁差；罗睺计都取平均交点；整宫制（Whole Sign）。
- 上升、行星所在星座与度数、宫位、二十七宿与足、入旺/落陷/入庙、逆行、D9。
- 维姆肖塔里大运（120 年）与当前大运里的小运；年按 365.2425 天。
- 流年：这一年经过的大运小运，木星、土星、罗睺、计都的换座日期（宫位分别从上升和月亮起算，标出七年半等土星位置），以及十二个太阳月（太阳入座日）。
- 时辰不详：按当地正午排，没有上升，以月亮所在星座为第一宫（Chandra Lagna），提示词里提醒不依赖上升。

精度用 Swiss Ephemeris 核对：`src/vedic/swisseph-reference.json` 是 pyswisseph 算出的十组参考值，`astro.test.ts` 要求行星与上升误差在 0.02° 以内（实际最大约 0.006°）。

## 提示词与分段

`src/prompt/vedic.ts`，标题见 `sectionsFor(kind, schools, 'vedic')`：
- 命盘总论：星盘总览、性格与心性、事业学业、财富、感情婚姻、大运走势、建议
- 流年运势：年度总览、大运与小运、事业、财运、感情、健康与心态、逐月提示（按太阳月）、建议

## 数据

仍用 `readings` 表。吠陀测算的 `spread_preset` 为 `vedic_natal`、`vedic_year`，其余字段同八字测算；`Reading.system` 区分，旧记录都读成八字。出生地随出生信息存在命主的 `cards.birth.place`。
